## 🎯 what we're building

### grainui + gpui - gpu-accelerated interfaces
10-100x performance over egui. buttery smooth graincard scrolling. retained-mode architecture.

### grainorder - permutation naming
6-char codes from 13 consonants (x b d g h j k l m n s v z). chronological + unique! no repeating characters.

### graindb - immutable database
time travel queries. never lose data. grainorder entity ids. datomic/datascript inspiration in steel.

### graintime - astronomical version control  
git branches with nakshatra, ascendant, solar house. cosmic awareness meets version control.

### steel - rust scheme lisp
pure rust+steel stack. safety meets elegance. r5rs compliant.

### icp + iroh - decentralized hosting
no aws, no servers. icp for compute, iroh for storage. fully distributed.

## 🌾 philosophy

### immutability as honesty
when you create a grainbranch, you're saying: "this work happened HERE, at THIS moment, under THESE stars." you can't change that. honest computing.

### grainorder = chronological + unique
timestamps AND unique ids in one! no uuid bloat, no timestamp collisions.

### head-insert vs tail-insert  
clear terminology. newest = head (small alphabet). oldest/archives = tail (large alphabet).

### glow g2 voice
patient teacher. asks questions. checks understanding. hand-holding explanations. no cheesy bro-y language.

### immutable grainbranches
this branch is frozen! share it with friends - it never changes.  
when we continue, we create a NEW grainbranch with new timestamp.
